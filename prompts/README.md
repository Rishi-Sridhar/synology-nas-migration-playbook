# Reusable AI-Agent Prompts

These prompts are templates for supervised infrastructure work. Replace placeholders only in a private session. Do not paste credentials, authenticated URLs, raw databases, torrent state, or private report bundles into an AI prompt.

- [Migration agent](migration-agent.md) — discovery through verified cutover
- [Cleanup review agent](cleanup-review-agent.md) — evidence-gated retirement planning

An agent should default to read-only discovery, separate facts from decisions, show exact scope before mutation, and stop on ambiguity. Human approval is not a substitute for fresh preconditions immediately before a destructive action.
